## 🛠️ 标准实战与全自动文档联动流程

1. **开启任务**：输入 `/task [id]`（如 `/task 001`），教练自动将任务同步为“🟡 进行中”并开始概念精讲；
2. **自主编码**：阅读任务卡片中的业务需求、API 提示与「编码前必读的坑」后，直接在 `src/exercises/` 对应代码文件中编写代码，并在浏览器中实时验证（**无需先向教练答辩思路**）；
3. **过程答疑与 Q&A 自动沉淀**：编码遇到任何疑问随时向教练提问，教练解答后**自动以标准 Q&A 沉淀至 `docx/questions/`**；
4. **代码审查与错题本自动更新**：输入 `/review` 请求教练审查，若排查出典型认知偏差，教练**自动追加至 `docx/mistakes.md`**；
5. **通关验收与里程碑自动归档**：代码修复并达到验收标准（DoD）后，教练**自动更新 `docx/learning.md` 与卡片勾选**，宣布通关！
