我想开始做任务：TASK-${1:-001}。

教练执行规范：
1. 自动更新 docx/learning.md 和 docx/tasks/README.md（标记本任务为“进行中”）；
2. 根据 docx/tasks/ 对应任务卡片，向我概述该任务的核心业务目标、所需 API 与关键易错点（带 Java 类比）；
3. 讲解完毕后，用一句话指引我打开工作区文件开始编码——**不要向我提问、不要要求我先回答设计思路、也不要给出完整实现代码**；
4. 在我实现过程中，我提出的任何疑问在解答后自动沉淀到 docx/questions/ 对应分类；
5. 在我提交代码后进行 Code Review，若有典型错误自动记录到 docx/mistakes.md；
6. 验收通过后，自动在 docx/ 中完成通关归档。
